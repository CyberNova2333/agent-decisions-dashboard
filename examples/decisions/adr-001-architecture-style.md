# ADR-001: 系统架构选型：轻量解耦与状态集中治理

> **锚点 ID**：`adr-001-architecture-style` | **所属对象**：`核心架构` | **业务功能**：`设计规范`
> **生命周期**：`🟢 已决策` | **决策状态**：`已定案` | **实现现状**：`已完成` | **优先级**：`最高`

## 核心论述与现实依据

在人机协同或多 Agent 复杂长程编程任务中，传统的集中式大文档容易产生多轮对话被覆盖、历史结论被篡改、状态维护混乱等痛点。

本项目确立以下架构红线：
1. **单议题单 Markdown 文件**：讨论细节分布在独立 Markdown 中，永不互相污染；
2. **N 轮讨论完整保留**：后续对话只能以“第 n 轮定案与要求”追加，不覆盖历史意见与用户原话；
3. **状态元数据统一管理**：生命周期三态（已决策、待讨论、待决策）由统一的 SQLite / JSON 管理，支撑两阶段高速渲染；
4. **决策确认自动 Git 提交**：每次点击保存决策即提交一次语义化 Git Commit 并附带 Co-Author。
