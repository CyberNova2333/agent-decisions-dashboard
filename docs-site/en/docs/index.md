# Quick Start

Agent Decisions Dashboard provides real-time decision tracking and structured audit logs for autonomous AI agents.

## Core Problems Solved

- **Pain Point 1**: Lack of transparent observability into multi-step agent reasoning and tool dispatch.
- **Pain Point 2**: Difficulty in reconstructing decision branches and reproducing transient tool failures.
- **Pain Point 3**: High overhead when capturing granular audit logs across distributed agent processes.

---

## Prerequisites

Node.js 20+, Rust 1.80+, pnpm 12.6.0.

---

## Quick Installation & Launch

```bash
# 1. Install project dependencies
pnpm install

# 2. Run local tests and verification
pnpm test
```
