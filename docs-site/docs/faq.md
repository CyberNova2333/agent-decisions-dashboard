# 常见问题与排错

以下汇总了日常使用与开发集成过程中最常见的问题解答：

### Q: 服务是否会向外部发送我的代码或决策数据？

**A**: 绝不。Agent Decisions Dashboard 设计原则为 100% 本地受信运行，所有数据落盘于本地 SQLite 与当前工作区的 Markdown 文件中，不含有任何形式的外部遥测或第三方上报。

### Q: 如果多个 Agent 同时写入同一个议题会发生冲突吗？

**A**: 服务内置了乐观版本控制与行级锁机制，当发生并发修改时，后到达的写入请求会收到带版本冲突提示的 409 状态码，并附带最新快照供其合并后重试。

### Q: 如何与本地 Git 提交联动？

**A**: 在请求体中传入 `"git_commit": true`，服务在写入 SQLite 和生成 Markdown 后，会自动调用本地配置的 Git 签名私钥生成规范的 Conventional Commit 提交。

## 故障排查通用步骤

1. **核对运行环境版本**：确保您的 Node.js / Python 或浏览器版本符合最低兼容要求；
2. **检查控制台报错日志**：绝大部分配置错误或权限拒绝在控制台中都有清晰的行号与原因提示；
3. **提交 Issue 反馈**：若确认遇到底层 Bug，欢迎前往 GitHub 仓库提交复现用例与诊断日志。
